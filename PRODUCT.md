# Arjun Portfolio — Product Definition

## What this is

A static portfolio for Apple Developer Academy review. It presents Kasimsetty Venkata Naga Arjun as a systems builder across robotics, AI, embedded hardware, and Swift-native product work.

## Audience

- Apple Developer Academy reviewers
- Engineering hiring managers and research collaborators
- Anyone evaluating depth across hardware + software + product

## Voice

Warm, precise, mechanical, human. Not corporate SaaS. Not generic “AI portfolio” editorial.

## Register

Brand / portfolio (design is the product).

## Core narrative

1. Who Arjun is and what he builds
2. FlexML as flagship (Apple-native systems story)
3. Four supporting projects showing range
4. About + contact for Academy context

## Success criteria

- Distinctive but readable in under 3 minutes
- Clear path: Home → Featured → Projects → Case studies
- Real project imagery and honest metrics
- Accessible, fast on mobile, no AI-slop tells

## Non-goals

- Blog, CMS, dark mode (v1), React migration
